# Cako The Cake Shop: demo website

A four-page demo site for **Cako The Cake Shop**, a vegetarian-only cake shop on Upper Kondhwa Road, Bibvewadi, Pune.
Design direction: "Midnight Patisserie, lit till twelve" (cocoa night, Bodoni Moda and Schibsted Grotesk, gold hairlines, one red for actions).
Plain HTML, CSS and JavaScript; the pages are generated by a small Node script. No framework, no runtime dependencies.

## Run it

```
npm install        # once: Vite, GSAP, Lenis
npm run dev        # generate the pages, then the Vite dev server on http://localhost:5173
npm run build      # generate the pages, then the production build in dist/ (minified, hashed CSS and JS)
npm run preview    # serve dist/ on http://localhost:4173 to check the build
npm run pages      # only regenerate the four pages and assets/css/site.css
```

Deploy: Vercel reads `vercel.json` (install `npm install`, build `npm run build`, output `dist`). Any static host works with the same two settings.

## How it is built

```
tools/build-pages.mjs        writes index/cakes/order/visit.html, sitemap.xml, robots.txt and bundles the CSS
tools/site/data.mjs          the 22 cakes (slug, name, category, description, demo prices) and small HTML helpers
tools/site/content.mjs       copy-deck data: alt text, FAQ bank, occasions, flavours, sample reviews, WhatsApp links
tools/site/shell.mjs         head, header, phone menu, footer, phone action bar, scripts
tools/site/home|cakes|order|visit.mjs   one module per page
tools/site/parts/*.mjs       markup for the signature components (photo cake, turntable, midnight clock, hours dial, size guide)
assets/css/src/*.css         styles: 00 fonts, 01 tokens, 02 base, 03 shell, 04 components, 10 home, 20 inner pages, 90 motion
assets/css/parts/*.css       component styles (joined in after the 0x files, before the page files)
assets/css/site.css          BUILT: never edit by hand
assets/js/site.js            Pune live clock and status, phone menu, cake filters, order slip, map facade
assets/js/motion.js          motion layer (GSAP + ScrollTrigger + Lenis), pause control, header behaviour
assets/js/parts/*.js         home behaviour and the components
src/entries/*.js            one Vite entry per page (GSAP 3.12.5, ScrollTrigger and Lenis 1.1.13 from npm, then the page scripts)
public/assets/fonts/                Bodoni Moda, Schibsted Grotesk, Sofia, Tiro Devanagari Marathi (OFL, subset)
public/assets/img/cakes/            the shop's 23 cake photos re-staged on one cocoa studio set (4:5, 480 and 900)
public/assets/img/cut/              transparent cut-outs of the cakes (240, 480, 960) and manifest.json
```

The design brief and copy deck the site was built from are in `../_workfiles/brief.md` and `../_workfiles/content.md`.

## What the pages do

- **Home**:
  - a three-tier revolving cake made of the shop's own photos (drag to turn; the tiers lift apart as you scroll);
  - a cake turntable with a paper place-card;
  - flavour families that deal a hand of photos, and swinging gift tags for occasions;
  - a midnight clock that sweeps to 12 as you scroll;
  - a size and servings guide that re-cuts the cake;
  - a sketch-to-cake reveal, a guest book of sample reviews and a live opening-hours dial;
  - FAQ answers that open WhatsApp with the question, and a live countdown to midnight.
- **Cakes**: all 22 cakes on lit shelves or as a price list, with filters and deep links (`cakes.html#chocolate`).
- **Order**: an order slip that writes the WhatsApp message for you, with a live preview of the name piped on the cake.
  - It can be pre-filled with `#order-<slug>`, `?occasion=` or `?size=`.
- **Visit**: the live hours dial, the seven-day hours, the address with copy and directions, and a map that loads on request.
- **Live in Pune time**: everything that depends on the hour uses Asia/Kolkata, whatever the visitor's time zone. That covers the status, the dial, the candles (lit 11 am to midnight) and the countdown.
- **Accessible motion**:
  - one "Pause motion" control, by the hero cake and in the footer, stops everything that moves on its own;
  - under reduced motion nothing animates and nothing is hidden;
  - without JavaScript every word and photo still shows.
